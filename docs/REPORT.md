# Git & GitHub Workflow Bootcamp – Report

## Project Overview
This project was created as part of the **Git & GitHub Workflow Bootcamp** task.
The goal of the task is to practice Git workflow concepts such as:

- Feature branches
- Conventional commits
- Pull Requests
- Merging branches
- Working with FastAPI project structure

---

## Project Structure
The project includes a simple FastAPI application with a healthcheck endpoint.

Main components:
- FastAPI application
- Virtual environment (venv)
- Feature branch workflow
- Documentation files

---

## Workflow Steps

1. Initialized Git repository
2. Created `main` branch
3. Created feature branch `feature/fastapi-healthcheck`
4. Added FastAPI project structure
5. Added README with run instructions
6. Used Conventional Commit messages
7. Merged `main` branch into feature branch
8. Created Pull Request on GitHub

---

## Result
The task was successfully completed following Git and GitHub best practices.
A Pull Request was created and is ready for review.
